# ComfyUI Forge V2.0.1

Status: Stable  
Patch Level: First Patch

ComfyUI Forge is the ComfyUI recovery module inside AI Forge.
It focuses on reproducible cold-start recovery for fresh cloud GPU pods.

## Recovery Layers

- Environment Layer
- Core Layer
- Data Layer
- Dependency Layer
- Network Layer
- Service Layer

## Quick Start

Upload private config files to /root, then run forge_start.sh.
